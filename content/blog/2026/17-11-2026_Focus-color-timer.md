👉 **Pruébalo ahora:** [focus-color-timer.clubinformatico.cl](https://focus-color-timer.clubinformatico.cl/)

## ⏳ ¿De qué se trata?

Focus Color Timer es un **temporizador tipo pomodoro** con un giro especial:  
[cada bloque de estudio pinta tu pantalla con un color único y aleatorio](#).

La idea es simple pero efectiva:

- Divides tu sesión en **bloques de estudio**
- Cada bloque tiene su propio color de fondo 🌈
- Entre bloques aparecen **intervalos blancos** para descansar ☁️
- Los colores van marcando tu avance, así *ves* cuánto llevas sin mirar el reloj

Es como darle ritmo y personalidad a tu concentración.

---

## ✨ Funcionalidades

- 🎲 **Colores únicos** generados automáticamente para cada bloque
- 🕑 **Intervalos inteligentes** que alternan estudio y descanso
- 🌈 **Transiciones suaves** entre colores, sin cambios bruscos
- 🚀 **Pantalla completa** con un solo clic
- 📊 **Seguimiento visual** de tu progreso
- 📱 **100% responsive**: funciona en el computador, la tablet o el celular

---

## 🎮 ¿Cómo se usa?

Usarlo toma menos de un minuto:

1. Ingresa la **cantidad de bloques** de estudio 📚
2. Define la **duración de cada bloque** en minutos ⏰
3. Presiona **"Iniciar Sesión"** 🚦
4. ¡Déjate guiar por los colores! 🎨
5. Descansa cuando la pantalla se ponga blanca ☁️

> 💡 **Pro tip:** haz clic sobre el timer para activar el **modo pantalla completa** y olvidarte de todas las distracciones.

## 🛠️ Simple por dentro

Una de las cosas más bonitas de este proyecto es lo **liviano** que es:  
está construido con **HTML, CSS y JavaScript**, todo en un solo archivo `index.html`.

No necesitas instalar nada. Si quieres correrlo en tu propio equipo, basta con:

```bash
git clone https://github.com/KrlitosForever/Focus_Color_Timer.git
```

y abrir el archivo `index.html` en tu navegador favorito. Así de fácil. ✅

Es un excelente ejemplo para quienes están comenzando en desarrollo web y quieren ver [cómo un proyecto pequeño puede resolver un problema real](#).
